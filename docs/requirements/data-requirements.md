## 1. ユーザー

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。重複しない。画面には出さない |
| ユーザー ID | 文字列 | ○ | トリム後 3〜15 文字の半角英数字と「_」。大文字・小文字を区別せずに重複しない。変更できない |
| 表示名 | 文字列 | ○ | トリム後 1〜30 文字 |
| パスワード | 文字列 | ○ | 8〜64 文字の半角文字、英字と数字を両方含む。元に戻せない形で保存する（要件定義書 N-18） |
| アバター | 画像 | | JPEG・PNG・WebP、5MB まで。正方形に切り取って持つ。ファイルは S3 に置き、データベースには置き場所だけを持つ |
| ステータスの絵文字 | 文字列 | | Unicode の絵文字 1 つ |
| ステータスの文 | 文字列 | | トリム後 0〜100 文字。改行は含められない |
| ステータスを消す日時 | 日時 | | この日時を過ぎたら、ステータスの絵文字と文を出さない。ないときは消すまで出す |
| ログインの失敗回数 | 数値 | ○ | 続けて失敗した回数 |
| ログインできない期限 | 日時 | | 5 回続けて失敗したときの 15 分後（要件定義書 N-19） |
| 登録日時 | 日時 | ○ | 自動で記録 |
| 更新日時 | 日時 | ○ | 自動で記録 |

プロフィール（アバター・表示名・ステータス）はすべてのワークスペースで共通とする。

## 2. ワークスペース

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。URL に使う |
| 名前 | 文字列 | ○ | トリム後 1〜50 文字。ほかのワークスペースと同じでもよい |
| オーナー | ユーザー | ○ | 作った人。変えられない |
| 作成日時 | 日時 | ○ | 自動で記録 |

1 人が作れるワークスペースは 10 個までとする（参加するワークスペースの数には上限を設けない）。削除したワークスペースは数えない。

オーナーがワークスペースを削除すると、そのワークスペースのメンバー・招待リンク・チャンネル・DM・メッセージ・添付（S3 のファイルを含む）・リアクション・メンションをすべて消す（要件定義書 FN-03）。

## 3. ワークスペースのメンバー

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ワークスペース | ワークスペース | ○ | |
| ユーザー | ユーザー | ○ | ワークスペースとユーザーの組み合わせは重複しない |
| 役割 | 文字列 | ○ | 「オーナー」「メンバー」のどちらか。オーナーはワークスペースごとに 1 人 |
| 参加日時 | 日時 | ○ | 自動で記録 |
| 最後に開いた会話 | 会話 | | ワークスペースを開いたときに出す会話（画面一覧 2 章） |

キックしたとき・オーナー以外のメンバーが自分で退出したときは、そのワークスペースのメンバーと、そのワークスペースのすべての会話のメンバーから外す。その人が送ったメッセージ・添付・リアクションは消さずに残す。キック・退出した人も、有効な招待リンクからまた参加できる。そのときは新しく参加した人として、チャンネルは general にだけ入り、前に入っていたほかのチャンネルには入り直さない。DM は前のもののメンバーに戻り、それまでのメッセージを読めて、また送れる（要件定義書 FN-05）。オーナーは退出できない。

## 4. 招待リンク

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける |
| ワークスペース | ワークスペース | ○ | |
| 招待の文字列 | 文字列 | ○ | URL に入れる、推測できない長い文字列。重複しない（要件定義書 N-22） |
| 有効期限 | 日時 | ○ | 作ってから 7 日後 |
| 取り消した日時 | 日時 | | オーナーが取り消したときに記録する |
| 作った人 | ユーザー | ○ | オーナー |
| 作成日時 | 日時 | ○ | 自動で記録 |

1 つの招待リンクは、期限までなら何人でも使える。期限切れ・取り消し済みのリンクは、作ってから 30 日たったらまとめて消す。

## 5. 会話（チャンネル・DM）

チャンネルと DM をまとめて「会話」とする。メッセージはどちらかの会話に属する。

### 5.1 チャンネル

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。URL に使う |
| ワークスペース | ワークスペース | ○ | |
| 名前 | 文字列 | ○ | トリム後 1〜80 文字。空白は含められない。同じワークスペースの中で、大文字・小文字を区別せずに重複しない |
| 説明 | 文字列 | | トリム後 0〜250 文字 |
| 種類 | 文字列 | ○ | 「公開」「プライベート」のどちらか。作った後は変えられない |
| general か | 真偽値 | ○ | ワークスペースを作ったときにできる general だけが「はい」。general は公開で、退出・削除できない |
| 作った人 | ユーザー | ○ | |
| 作成日時 | 日時 | ○ | 自動で記録 |

チャンネルを削除すると、そのチャンネルのメッセージ・スレッドの返信・添付（S3 のファイルを含む）・リアクション・メンションもすべて消す。

### 5.2 DM

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。URL に使う |
| ワークスペース | ワークスペース | ○ | |
| 2 人のユーザー | ユーザー 2 人 | ○ | 同じワークスペースのメンバーで、別の人。同じワークスペースで同じ 2 人の DM は重複しない |
| 作成日時 | 日時 | ○ | 自動で記録 |

DM は、どちらかがキック・退出しても消さない。残った人は、その人との DM を読めるが、新しいメッセージは送れない。その人がまた参加したときは、その人を同じ DM のメンバーに戻し（3 章）、同じ DM をまた使う。

### 5.3 会話のメンバー

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| 会話 | 会話 | ○ | |
| ユーザー | ユーザー | ○ | 会話とユーザーの組み合わせは重複しない。そのワークスペースのメンバーに限る |
| 参加日時 | 日時 | ○ | 自動で記録 |
| 最後に読んだメッセージ | メッセージ | | その会話を開いたときに、いちばん新しいメッセージを記録する。これより新しいほかの人のメッセージ（スレッドの返信を除く）を未読とする |

チャンネルは参加した人がメンバーになる。DM は 2 人がメンバーになる。公開チャンネルはメンバーでなくても読めるが、メッセージを送るには参加する。未読は、その会話のメンバーにだけ出す。メンションの通知は 6.3 による。

## 6. メッセージ

スレッドの返信もメッセージの 1 つとして持つ。

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける。重複しない。新しいメッセージほど大きい |
| 会話 | 会話 | ○ | |
| 送った人 | ユーザー | ○ | |
| 親メッセージ | メッセージ | | スレッドの返信のときだけ持つ。同じ会話のメッセージで、親メッセージを持たないもの（返信への返信はできない） |
| 本文 | 文字列 | ○ | トリム後 0〜4,000 文字。改行を含められる。Markdown 記法で書ける。添付がないときは 1 文字以上 |
| 送った日時 | 日時 | ○ | 自動で記録。並び順に使う |
| 編集日時 | 日時 | | 最後に編集した日時。編集していないメッセージにはない |
| 削除日時 | 日時 | | スレッドの返信がある親メッセージを削除したときだけ記録し、本文・添付・リアクションを消して「このメッセージは削除されました」と出す。返信がないメッセージ・スレッドの返信は、削除したらデータごと消す |

親メッセージには、返信の件数と最後の返信の日時を出す（データ設計書で持ち方を決める）。

### 6.1 添付ファイル

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 数値 | ○ | アプリが自動で付ける |
| メッセージ | メッセージ | ○ | 1 通に 4 個まで |
| 種類 | 文字列 | ○ | 「画像」「動画」のどちらか |
| 形式 | 文字列 | ○ | 画像は JPEG・PNG・GIF・WebP、動画は MP4・WebM。ファイルの中身で確かめる |
| 大きさ | 数値 | ○ | バイト数。画像は 10MB（10,485,760 バイト）以下、動画は 100MB（104,857,600 バイト）以下 |
| 元のファイル名 | 文字列 | ○ | 画面に出すためだけに使う。255 文字まで |
| 置き場所 | 文字列 | ○ | S3 の中での場所（キー）。重複しない。元のファイル名は使わない |
| 縮小した画像の置き場所 | 文字列 | | 画像のときだけ持つ。一覧に並べるための、長い辺を 800px までに縮めた画像の S3 の中での場所（要件定義書 FN-09）。元の画像が 800px 以下のときは元の画像を使う。アニメーションする GIF・WebP の縮小した画像は最初のコマだけの静止画とし、押して拡大したとき（G-17）に元の画像を動かして出す |
| 幅・高さ | 数値 | | 画像と動画の縦横の大きさ（画面で場所を先に取っておくため）。取れないときはない |
| 並び順 | 数値 | ○ | 0〜3 |

上の形式に当てはまらないファイル（SVG・HTML など、画像の拡張子を付けたものを含む）は受け付けない。画面に渡すときは、記録した形式をファイルの種類（Content-Type）として固定して渡し、ブラウザがほかの種類として開かないようにする（要件定義書 N-21）。

ファイルそのものは S3 に置き、データベースには上の項目だけを持つ（要件定義書 P-2）。送らずに捨てたアップロード済みのファイルは、1 日 1 回まとめて消す。

### 6.2 リアクション

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| メッセージ | メッセージ | ○ | |
| 付けた人 | ユーザー | ○ | |
| 絵文字 | 文字列 | ○ | Unicode の絵文字 1 つ。メッセージ・付けた人・絵文字の組み合わせは重複しない |
| 付けた日時 | 日時 | ○ | 自動で記録。絵文字の並び順（最初に付けられた順）に使う |

1 つのメッセージに付けられる絵文字の種類は 50 までとする。

### 6.3 メンション

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| メッセージ | メッセージ | ○ | |
| メンションされた人 | ユーザー | ○ | 本文の「@ユーザー ID」から、送ったときと編集したときに作り直す。そのワークスペースのメンバーに限る。自分へのメンションは作らない。メッセージとメンションされた人の組み合わせは重複しない |
| 読んだか | 真偽値 | ○ | メンションされた人がそのメッセージのある会話（スレッドの返信ならそのスレッド）を開いたら「はい」にする。「いいえ」の件数を通知に出す（FN-14） |

メンションは、送ったときにその会話を見られる人（要件定義書 3.1）へのものだけを記録・通知する。公開チャンネルでは、チャンネルに参加していないワークスペースのメンバーにも通知する。プライベートチャンネルと DM では、その会話のメンバーでない人へのメンションは記録も通知もしない（後で参加しても、参加前のメンションは出さない。要件定義書 N-14）。本文の「@ユーザー ID」はそのまま文字として出す。

## 7. リフレッシュトークン

ログインしたままにするために、ログインした人に渡す文字列である。JWT（要件定義書 N-24）の有効期限が切れたときに、これを使って新しい JWT を受け取る。

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ユーザー | ユーザー | ○ | ログインした人。1 人が複数のブラウザでログインしたときは、ブラウザごとに 1 つ持つ |
| トークン | 文字列 | ○ | 推測できない長い文字列。データベースには元に戻せない形（ハッシュ）で保存する |
| 有効期限 | 日時 | ○ | 発行してから 14 日後 |
| 無効にした日時 | 日時 | | 使って新しいものに替えたとき、ログアウトしたときに記録する |
| 発行日時 | 日時 | ○ | 自動で記録 |

有効期限を過ぎたものは、1 日 1 回まとめて消す。

## 8. 上限

| 対象 | 上限 |
| --- | --- |
| メッセージの本文 | 4,000 文字 |
| 1 通のメッセージの添付 | 4 個 |
| 添付の画像 1 個の大きさ | 10MB |
| 添付の動画 1 個の大きさ | 100MB |
| アバターの大きさ | 5MB |
| 1 つのメッセージのリアクションの絵文字の種類 | 50 |
| ステータスの文 | 100 文字 |
| ワークスペースの名前 | 50 文字 |
| 1 人が作れるワークスペース | 10 個 |
| チャンネルの名前・説明 | 80 文字・250 文字 |
| 招待リンクの有効期限 | 7 日 |
| 検索の文字 | 100 文字 |
| ユーザー・ワークスペースのメンバー・チャンネル・メッセージ・リアクションの件数 | 上限なし（性能の目標は要件定義書 N-1〜N-7 の条件で確かめる） |

## 9. ブラウザの通知の設定

ブラウザの通知（要件定義書 FN-14）のオン・オフは、ブラウザごとに覚え、サーバーには保存しない。通知を出すには、ブラウザが通知を許可していることと、この設定がオンであることの両方が要る。初めは「オフ」とする。

## 10. 詳細

データの詳しい構造（ER 図）はデータ設計書で定める。

## 11. 保存する個人情報

ユーザー ID・表示名・アバター・ステータスと、元に戻せない形にしたパスワードのみを保存する。メールアドレス・本名・電話番号は保存しない。メッセージ・添付は、送った会話を見られる人（要件定義書 3.1）だけに見える。DM は 2 人だけに見え、オーナーや作成者の画面からも見られない（作成者はデータベースを直接見られるため、この点は利用者に操作マニュアルで知らせる）。
