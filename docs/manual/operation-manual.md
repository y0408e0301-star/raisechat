## 1. はじめに

RaiseChat は、仲間ごとの「ワークスペース」の中で、話題ごとの「チャンネル」や 2 人だけの「ダイレクトメッセージ（DM）」でやり取りするチャットアプリです。送ったメッセージは、画面を開き直さなくても相手の画面にすぐ出ます。

- ワークスペースに入るには、そのワークスペースを作った人（オーナー）から「招待リンク」をもらいます（4 章）
- ワークスペースの中のものは、そのワークスペースのメンバーにしか見えません。ほかのワークスペースの人からは、名前も含めて何も見えません
- **DM は 2 人だけに見えます。ただし、RaiseChat の作成者はデータベースを直接見られるため、DM も含めて中身を読むことができます。** 人に知られて困ることは書かないでください（12.3）
- 音声・ビデオ通話、画像・動画以外のファイルの添付、メールでの通知はありません（17 章）

### 1.1 使える環境

| 機器 | ブラウザ |
| --- | --- |
| パソコン（Windows 11） | Google Chrome、Microsoft Edge、Mozilla Firefox |
| パソコン（macOS 14 以降） | Safari、Google Chrome |
| iPhone（iOS 17 以降） | Safari |
| Android 14 以降 | Google Chrome |

- どれも最新版を使ってください。アプリのインストールは要りません。ブラウザで URL を開きます
- インターネットへの接続が必要です。つながっていないときは、画面の上に「インターネットに接続されていません。接続を確認してください。」と出ます。つながると消えます
- 費用を抑えるため、使わない間はサーバーを止めています。止めている間に開くと「RaiseChat は止めています」と出ます。動かしている時間に開き直してください
- iPhone では、ブラウザの通知（14.3）は出ません。サイドバーの未読・メンションの印（14.1）は出ます

### 1.2 画面の見方

ワークスペースを開くと、次のチャット画面になります。

```
┌──────────────────────────────────────────────────────────────────────────┐
│ RaiseChat ▸ 仲間うち   [🔍 メッセージを検索        ]  @ 2  (た) ログアウト │ ← ヘッダー
├────────────────────┬─────────────────────────────────┬───────────────────┤
│ 仲間うち         ▾ │ # general                  👥 12 ⓘ │ スレッド        ✕ │
│                    │ 全体への連絡はここに               │                   │
│ @ メンション     2 │─────────────────────────────────│ （親メッセージ）    │
│ 🔍 チャンネルを探す │ ──────── 11月10日（月） ─────────│ ── 2 件の返信 ──  │
│                    │ (は) はなこ  10:02                 │ （返信の一覧）      │
│ チャンネル       ＋ │   土曜の集合は駅前でいいですか？   │                   │
│  # general         │   [👍 3] [🎉 1] [😀＋]             │                   │
│  # 旅行の計画   ①  │   (た)(じ) 2 件の返信  最終 10:07  │                   │
│  **# 雑談**        │                                    │                   │
│  🔒 運営           │ ┌───────────────────────────────┐ │ ┌───────────────┐ │
│                    │ │ # general へのメッセージ       │ │ │ 返信する…     │ │
│ ダイレクトメッセージ ＋│ │ 📎 B I S </> 😀      [送信 ➤] │ │ └───────────────┘ │
│  **(は) はなこ ③** │ └───────────────────────────────┘ │                   │
└────────────────────┴─────────────────────────────────┴───────────────────┘
   サイドバー              会話                               スレッドのパネル
```

| 部分 | できること |
| --- | --- |
| RaiseChat | 押すとワークスペースの一覧に戻る（3.2） |
| ▸ 仲間うち（ワークスペースの名前） | 押すと、そのワークスペースで最後に開いた会話に戻る |
| メッセージを検索 | メッセージを探す（13 章） |
| @ 2 | 自分あてのメンションの一覧を開く。数字は読んでいないメンションの数（14.2） |
| (た)（自分のアバター） | 押すと「プロフィールの設定」（15 章）・「ワークスペースの一覧」のメニュー |
| ログアウト | ログアウトする（2.3） |
| サイドバー | ワークスペースの名前（押すとメニュー）、メンション、チャンネルを探す、自分が入っているチャンネルと DM の一覧。🔒 はプライベートチャンネル。太字は未読あり、丸の数字は件数（14.1） |
| 会話 | 選んだチャンネルか DM のメッセージと、入力欄 |
| スレッドのパネル | スレッドを開いたときだけ出る（8 章）。「✕」で閉じる |

スマートフォンなど画面の幅が狭いときは、サイドバー・会話・スレッドのパネルを 1 つずつ画面いっぱいに出します。会話を選ぶと会話の画面になり、左上の「←」でサイドバーに戻ります。ヘッダーの検索欄は 🔍 のボタンだけになり、押すと検索欄が開きます。

## 2. アカウント

### 2.1 アカウントを作る

1. URL を開き、ログイン画面の「アカウントを作る」を押す
2. 次の 4 つを入れて「登録する」を押す

| 項目 | 決まり |
| --- | --- |
| ユーザー ID | 3〜15 文字の半角英数字と「_」。ほかの人と同じ ID は使えません（大文字と小文字の違いだけでも同じ ID とみなします）。メンションに使います（「@taro_y」）。**後から変えられません** |
| 表示名 | 1〜30 文字。メッセージに名前として出ます。ほかの人と同じでもかまいません。後から変えられます |
| パスワード | 英字と数字を両方含む 8〜64 文字の半角文字。記号・空白も使えます |
| パスワード（確認） | パスワードと同じものをもう一度 |

- 条件に合わない項目があると、その入力欄の下に理由が出ます
- 登録するとそのままログインし、ワークスペースの一覧が開きます。初めはどのワークスペースにも入っていません（3 章・4.4）
- メールアドレスは登録しません。**パスワードを忘れたときに再発行する方法はありません。** 忘れたときは新しいアカウントを作り、オーナーに招待リンクをもらい直してください

### 2.2 ログインする

1. ログイン画面でユーザー ID とパスワードを入れて「ログイン」を押す
2. ワークスペースの一覧が開きます。ログインする前に開こうとしていた画面（招待リンクなど）があれば、その画面が開きます

- 一度ログインすると、**最後に使ってから 14 日間は、ブラウザを閉じてもログインしたまま**です。14 日間使わなかったときは、ログインし直してください
- ユーザー ID は大文字と小文字を区別しません
- **パスワードを 5 回続けて間違えると、そのユーザー ID では 15 分間ログインできません。** 15 分たってから、正しいパスワードでログインしてください。すでにログインしている画面は、そのまま使えます

### 2.3 ログアウトする

ヘッダーの「ログアウト」を押します。確認なしでログアウトし、ログイン画面に戻ります。送らずに入力欄に残していた文は消えます。

共用のパソコンでは、使い終わったら必ずログアウトしてください。ブラウザの通知をオンにしていたときは、ログアウトの前にオフに戻してください（14.4）。

### 2.4 退会について

退会（アカウントの削除）はありません。ワークスペースから抜けたいときは、ワークスペースから退出してください（5.3）。

## 3. ワークスペース

### 3.1 ワークスペースを作る

1. ワークスペースの一覧で「ワークスペースを作る」を押す
2. 名前（50 文字まで）を入れて「作る」を押す

- 作った人がそのワークスペースのオーナーになり、チャンネル「general」が自動でできます。作るとすぐ general が開きます
- 1 人が作れるワークスペースは 10 個までです（削除したものは数えません）。招待されて入るワークスペースの数には上限はありません
- 仲間を入れるには、招待リンクを作って渡します（4 章）

### 3.2 ワークスペースを切り替える

ワークスペースの一覧には、自分が入っているワークスペースが名前の順に出ます。押すと、そのワークスペースで最後に開いた会話が開きます（初めてなら general）。

- 自分がオーナーのワークスペースには「オーナー」と出ます
- 未読があるワークスペースは太字になり、読んでいないメンションがあれば件数が出ます（14.1）
- チャット画面からは、ヘッダーの「RaiseChat」、自分のアバターのメニューの「ワークスペースの一覧」、サイドバーのワークスペースの名前のメニューの「ワークスペースの一覧」で戻れます

### 3.3 ワークスペースを削除する（オーナー）

1. サイドバーのワークスペースの名前を押し、メニューの「メンバー」を押す
2. 画面の下の「ワークスペースを削除」を押す
3. 確認の画面にワークスペースの名前をそのまま入れ、「削除」を押す（名前が同じになるまで押せません。「キャンセル」で何もせずに戻ります）

- **すべてのチャンネル・DM・メッセージ・画像・動画・招待リンクが消え、元に戻せません**
- そのワークスペースを開いていたメンバーの画面には「ワークスペース「（名前）」は削除されました。」と出て、ワークスペースの一覧に戻ります
- オーナーはワークスペースから退出できません。やめたいときは削除してください。オーナーをほかの人に引き継ぐことはできません

## 4. 招待

ワークスペースに人を入れられるのはオーナーだけで、招待リンクを使います。

### 4.1 招待リンクを作る（オーナー）

1. サイドバーのワークスペースの名前を押し、メニューの「招待リンクの管理」を押す
2. 「招待リンクを作る」を押す。一覧の先頭に新しいリンクが出ます
3. そのリンクの「コピー」を押す。「招待リンクをコピーしました。」と出て、リンクの URL がコピーされます

- **リンクは作ってから 7 日間使えます。期限までなら何人でも参加できます**
- 一覧には、リンクごとに状態（有効・期限切れ・取り消し済み）と期限が出ます。「コピー」は有効なリンクで何度でも押せます
- 期限切れ・取り消し済みのリンクは、作ってから 30 日たつと一覧から消えます

### 4.2 招待リンクを渡す（オーナー）

コピーした URL を、メッセージアプリやメールに貼り付けて、入ってほしい人に送ります。

- **リンクを知っている人は誰でも参加できます。** SNS など、多くの人が見られる場所には貼らないでください。送るのは、入ってほしい人だけにしてください
- 7 日を過ぎたら、新しいリンクを作って渡し直してください
- 相手がまだアカウントを持っていなくてもかまいません。リンクを開いた画面から、アカウントを作って参加できます（4.4）

### 4.3 招待リンクを取り消す（オーナー）

意図しない人にリンクが渡ったときや、もう人を入れないときは、リンクを取り消します。

1. 「招待リンクの管理」で、そのリンクの「取り消す」を押す
2. 確認の画面で「取り消す」を押す

- 取り消したリンクでは、その後は誰も参加できません。すでに参加した人はそのままです。外したいときはキックしてください（5.2）
- キックした人も、有効な招待リンクからまた参加できます。戻ってほしくないときは、その人が知っているリンクを取り消し、新しいリンクを作って、ほかの人にだけ渡してください

### 4.4 招待されたとき（参加する）

1. もらった招待リンクを開く
2. 「「（ワークスペースの名前）」に招待されています」と出ます
   - ログインしていないとき：「ログイン」か「アカウントを作る」を押し、ログイン（または登録）する。終わるとこの画面に戻ります
3. オーナーの名前とメンバーの人数を確かめて「参加する」を押す

- 参加すると、そのワークスペースの general に入り、general が開きます
- 「この招待リンクは期限切れか、取り消されています。招待した人に新しいリンクをもらってください。」と出たときは、オーナーに新しいリンクを作ってもらってください
- すでに参加しているワークスペースのリンクを開いたときは、「すでにこのワークスペースに参加しています。」と出て、そのワークスペースが開きます

## 5. メンバー

### 5.1 メンバーの一覧を見る

サイドバーのワークスペースの名前を押し、メニューの「メンバー」を押します。オーナーを先頭に、表示名の順でメンバーが出ます。

- 上の欄に文字を入れると、表示名かユーザー ID にその文字を含む人だけに絞れます
- 名前を押すと、その人のプロフィールが出ます。「メッセージを送る」で DM を始められます（12 章）

### 5.2 メンバーをキックする（オーナー）

1. メンバーの一覧で、外す人の「キック」を押す
2. 確認の画面で「キック」を押す

- キックされた人は、そのワークスペースのすべてのチャンネルから外れ、開いていた画面には「ワークスペース「（名前）」から外されました。」と出てワークスペースの一覧に戻ります。誰がキックしたかは知らせません
- キックされた人が送ったメッセージは消えずに残ります。消したいときは、メッセージを 1 つずつ削除してください（7.5）
- キックされた人も、有効な招待リンクからまた参加できます（4.3）

### 5.3 ワークスペースから退出する（オーナー以外）

1. メンバーの一覧の下の「ワークスペースから退出」を押す
2. 確認の画面で「退出」を押す

- すべてのチャンネルから外れ、ワークスペースの一覧に戻ります。送ったメッセージは残ります
- **もう一度入るには、オーナーに招待リンクをもらう必要があります**

### 5.4 抜けた人がまた参加したとき

キック・退出した人が招待リンクからまた参加したときは、新しく参加した人と同じく general にだけ入ります。前に入っていたほかのチャンネルには、もう一度参加（プライベートチャンネルは招待）してもらってください。DM は前のものに戻り、それまでのメッセージを読めて、また送れます。

## 6. チャンネル

### 6.1 公開チャンネルとプライベートチャンネル

| 種類 | 印 | 見られる人 | 入り方 |
| --- | --- | --- | --- |
| 公開チャンネル | # | ワークスペースのメンバー全員（参加していなくても読めます） | 自分で参加する（6.3） |
| プライベートチャンネル | 🔒 | そのチャンネルのメンバーだけ。**オーナーでも、入っていなければ見られません** | チャンネルのメンバーに招待してもらう（6.5） |

- general はワークスペースのメンバー全員が入っている公開チャンネルで、退出・削除できません
- チャンネルの名前の変更、公開とプライベートの切り替えはできません。変えたいときは新しいチャンネルを作ってください

### 6.2 チャンネルを作る

1. サイドバーの「チャンネル」の「＋」を押す（「チャンネルを探す」の画面の「チャンネルを作る」でも同じ）
2. 次を入れて「作る」を押す

| 項目 | 決まり |
| --- | --- |
| 名前 | 1〜80 文字。空白は入れられず、入れると「-」に変わります。同じワークスペースにある名前は使えません |
| 説明（任意） | 250 文字まで |
| 種類 | 「公開」か「プライベート」（初めは公開） |

- ワークスペースのメンバーなら誰でも作れます。作った人はそのチャンネルに入り、すぐ開きます
- 公開チャンネルを作っても、ほかの人には知らせません。「チャンネルを探す」で見つけてもらうか、メッセージで知らせてください

### 6.3 チャンネルを探して参加する

1. サイドバーの「チャンネルを探す」を押す
2. 公開チャンネルと、自分が入っているプライベートチャンネルが名前の順に出ます。上の欄に文字を入れると、名前で絞れます
3. 入りたいチャンネルの「参加する」を押す

- 入っているチャンネルには「参加中」と出ます
- チャンネルの名前を押すと、参加せずに中を読めます。このときは入力欄の代わりに「このチャンネルに参加すると、メッセージを送れます。」と「参加する」が出ます。参加するまでは、メッセージ・リアクション・スレッドの返信はできません
- 参加する前のメッセージは、未読に数えません

### 6.4 チャンネルの詳細を見る

会話の上のチャンネルの名前（または「👥 人数」「ⓘ」）を押すと、チャンネルの名前・説明・種類・作った人と日時・メンバーの一覧が出ます。メンバーは名前で絞れます。

### 6.5 プライベートチャンネルに人を招待する

プライベートチャンネルのメンバーなら、誰でも招待できます。

1. チャンネルの詳細で「メンバーを招待」を押す
2. 名前で探して、招待する人にチェックを付ける（1 回に 50 人まで）
3. 「招待する（人数）」を押す

招待された人のサイドバーには、すぐにそのチャンネルが出ます。招待できるのは、同じワークスペースのメンバーだけです。

### 6.6 チャンネルから退出する

チャンネルの詳細で「チャンネルから退出」を押します（general にはありません）。

- 公開チャンネルは確認なしで退出します。退出した後も、「チャンネルを探す」から読めます
- プライベートチャンネルは確認の画面で「退出」を押します。**退出すると見られなくなり、もう一度入るにはメンバーに招待してもらう必要があります**
- 退出すると、サイドバーから消え、general に移ります

### 6.7 チャンネルを削除する（オーナー）

1. チャンネルの詳細で「チャンネルを削除」を押す（general にはありません）
2. 確認の画面で「削除」を押す

- **チャンネルの中のメッセージ・スレッドの返信・画像・動画がすべて消え、元に戻せません**
- そのチャンネルを開いていた人の画面には「チャンネル「#（名前）」は削除されました。」と出て、general に移ります
- プライベートチャンネルは、オーナーがそのチャンネルに入っているときだけ削除できます

## 7. メッセージ

### 7.1 読む

サイドバーでチャンネルか DM を押すと、最新の 50 件のメッセージが、古いものが上になるように出ます。

- 読んでいないメッセージがあるときは、最初の未読の上に「新着」の線が出ます
- 上へスクロールすると、その前の 50 件が出ます。いちばん初めまで戻ると「このチャンネルはここから始まります。」と出ます
- ほかの人が送ったメッセージは、開き直さなくてもすぐ出ます。上の方を読んでいるときは「↓ 新しいメッセージ」が出て、押すといちばん下に移ります
- 日付が変わるところに「11月10日（月）」のような区切りが出ます。同じ人が 5 分以内に続けて送ったメッセージは、名前を省いて詰めて出ます
- 時刻にマウスを乗せると、年月日と秒まで出ます

### 7.2 送る

入力欄に書いて Enter キーか「送信 ➤」を押します。

- **改行は Shift＋Enter** です。日本語の変換を確定する Enter では送りません
- 本文は 4,000 文字までです。残りが 200 文字を切ると、入力欄の右下に残りの文字数が出ます。超えると「メッセージは 4,000 文字までです。」と出て、送れません（削って文字数を減らせば送れます）
- 送ったメッセージは、届くまで薄く「送信中…」と出ます
- 送らずにほかの会話に移っても、入力した文は会話ごとに残り、戻ると入力欄に戻ります（ログアウトしたり、画面を閉じたりすると消えます）

### 7.3 文字を飾る（Markdown 記法）

次の書き方で文字を飾れます。入力欄の「B」「I」「S」「</>」を押すと、選んだ文字の前後に記号を入れます。

| 書き方 | 見た目 |
| --- | --- |
| `**太字**` | **太字** |
| `*斜体*` または `_斜体_` | *斜体* |
| `~~取り消し線~~` | ~~取り消し線~~ |
| `` `コード` `` | 等幅の文字で枠つき |
| 「```」だけの行で前後を囲む | 複数行のコードを、枠の中にそのまま出す |
| 行頭に `> ` | 引用（左に線） |
| 行頭に `- `・`* `・`1. ` | 箇条書き・番号付きの箇条書き |
| http:// か https:// で始まる URL | リンク。押すと新しいタブで開く |

見出し・表・画像の書き方や HTML のタグは使えず、書いたままの文字で出ます。

入力欄の「😀」を押すと、絵文字の一覧から選んで本文に入れられます。

### 7.4 直す

1. 自分のメッセージにマウスを乗せ（スマートフォンでは長押し）、「✎」（編集）を押す
2. 本文を直して Enter キーか「保存」を押す（Esc キーか「キャンセル」でやめる）

- 直したメッセージの時刻の後ろには「（編集済み）」と出ます。同じ会話を開いている人の画面にもすぐ出ます
- 添付は「×」で外せますが、足すことはできません。本文を空にして添付もすべて外すことはできません（消したいときは削除してください）
- ほかの人のメッセージは、オーナーでも直せません

### 7.5 削除する

1. メッセージにマウスを乗せ（スマートフォンでは長押し）、「🗑」（削除）を押す
2. 確認の画面で「削除」を押す

- **消したメッセージは元に戻せません。** 添付・リアクションも消えます
- オーナーは、自分が見られる会話のほかの人のメッセージ（スレッドの返信を含む）も削除できます。不適切なメッセージを見つけたときに使ってください。DM の中のほかの人のメッセージは、オーナーでも削除できません
- スレッドの返信があるメッセージを消したときは、「このメッセージは削除されました。」と出て、スレッドは残ります

### 7.6 送れなかったとき

送れなかったメッセージには「送信できませんでした。」と「もう一度送る」「取り消す」が出ます。入力した文は消えません。

- 「もう一度送る」：同じメッセージを送り直します
- 「取り消す」：一覧から消して、本文と添付を入力欄に戻します

## 8. スレッド

あるメッセージへの返事を、そのメッセージの下にまとめるのがスレッドです。返信は会話の流れには出ないので、ほかの話に埋もれません。

1. メッセージにマウスを乗せ（スマートフォンでは長押し）、「💬」（スレッドで返信）を押す
2. 右にスレッドのパネルが開きます。下の「返信する…」に書いて送る

- 返信があるメッセージの下には「（件数）件の返信」と最後の返信の時刻が出ます。押すとスレッドのパネルが開きます
- 返信の送り方・飾り・添付・メンション・直し方・削除のしかたは、メッセージと同じです（7 章）
- 返信への返信はできません。返信をチャンネルにも送ることはできません
- スレッドの返信は会話の未読には数えません。返信の中で自分がメンションされたときは、メンションとして数えます（14.1）
- パネルは「✕」（スマートフォンでは「←」）で閉じます

## 9. 画像・動画を添付する

### 9.1 添付のしかた

次のどれでも添付できます。

- 入力欄の「📎」を押してファイルを選ぶ
- ファイルを会話の画面に重ねて落とす（「ドロップして添付」と出ます）
- コピーした画像を入力欄に貼り付ける

| 種類 | 形式 | 大きさ |
| --- | --- | --- |
| 画像 | JPEG・PNG・GIF・WebP | 1 つ 10MB まで |
| 動画 | MP4・WebM | 1 つ 100MB まで |

- 1 つのメッセージに 4 つまでです。5 つ以上選ぶと「添付できるのは 1 通に 4 個までです。」と出て、5 つ目からは添付しません
- 選ぶとすぐアップロードが始まり、入力欄の上に進み具合が出ます。**すべて終わるまで「送信」は押せません。** 大きな動画は時間がかかります
- 「×」で外せます。失敗したときは「ファイルをアップロードできませんでした。もう一度お試しください。」と「もう一度」が出ます。外すか、もう一度アップロードするまで送れません
- 本文がなくても、添付だけで送れます

> **写真の位置情報に注意してください。** スマートフォンで撮った写真には、撮った場所の情報（位置情報）が入っていることがあります。**RaiseChat は元の画像をそのまま保存し、位置情報を消しません。** 会話のメンバーは元の画像をダウンロードできるので、自宅などで撮った写真を送るときは、先に端末の設定や写真アプリで位置情報を消してください。

### 9.2 見る

- 画像は小さくして並べます。押すと大きく出ます。2 つ以上あるときは「‹」「›」（キーボードの左右の矢印キー）で切り替えます。上の「ダウンロード」で元の画像を保存できます。「✕」か Esc キーで閉じます
- 動くGIF・WebP は、一覧では止まった絵で、大きくしたときに動きます
- 動画は再生ボタンを押すと再生します（自動では再生しません）。全部を読み込むのを待たずに始まります。下の「ダウンロード」で保存できます
- 「この動画はこのブラウザでは再生できません。」と出たときは、「ダウンロード」で保存して、端末の動画のアプリで見てください

## 10. 絵文字リアクション

メッセージに絵文字で手軽に反応できます。

- **付ける**：メッセージにマウスを乗せ（スマートフォンでは長押し）、「😀」（リアクション）を押して絵文字を選ぶ。メッセージの下の「😀＋」からも選べます。絵文字の一覧は名前（日本語）で探せ、最近使ったものが先に出ます
- **同じ絵文字を足す・外す**：メッセージの下に並んでいる絵文字を押すと、自分の分を付けます。もう一度押すと外します。自分が付けた絵文字は枠の色が変わります
- **誰が付けたか見る**：並んでいる絵文字にマウスを乗せる（スマートフォンでは長押し）と、付けた人の名前が出ます
- 1 つのメッセージに、違う絵文字をいくつでも付けられます。1 つのメッセージに付く絵文字の種類は 50 までです
- 参加していない公開チャンネル・相手が抜けた DM・削除されたメッセージには付けられません

## 11. メンション

メッセージの中に「@ユーザー ID」と書くと、その人に呼びかけられます。メンションされた人には通知が届きます（14 章）。

1. 入力欄に「@」を入れ、続けて名前かユーザー ID の一部を入れる
2. 候補が出るので、上下の矢印キーで選んで Enter キーか Tab キー（または押す）。「@ユーザー ID 」が入ります

- 候補を使わずに「@taro_y」と手で書いてもメンションになります
- 候補に「チャンネルにいません」と出る人も、公開チャンネルなら読めるのでメンションが届きます。プライベートチャンネルでは、チャンネルのメンバーしか候補に出ません
- 送ったメッセージのメンションは色付きで出ます。自分あてのメンションを含むメッセージは、背景の色が変わります。名前を押すとその人のプロフィールが出ます
- 一度に呼びかけられるのは 1 人ずつです（「@channel」のような全員へのメンションはありません）
- 直してメンションを足すと、足した人にだけ通知が届きます

## 12. ダイレクトメッセージ（DM）

同じワークスペースのメンバーと、2 人だけでやり取りできます。

### 12.1 DM を始める

- サイドバーの「ダイレクトメッセージ」の「＋」を押し、相手を名前で探して押す
- または、人の名前を押して出たプロフィールの「メッセージを送る」を押す

すでにその人との DM があれば、それが開きます。DM のメッセージ・スレッド・添付・リアクション・メンションの使い方は、チャンネルと同じです。

- 作ったばかりの DM は、最初のメッセージを送るまで相手のサイドバーには出ません
- サイドバーの DM は、最後のメッセージが新しい順に並びます
- 3 人以上の DM や、自分あての DM はありません

### 12.2 相手がワークスペースを抜けたとき

相手がキック・退出したときは、それまでの DM は読めますが、送れません。入力欄の代わりに「（表示名）さんはこのワークスペースにいないため、メッセージを送れません。」と出ます。相手がまた参加すると、また送れます。

### 12.3 DM の中身を見られる人

- DM は 2 人だけに見えます。ワークスペースのオーナーや、ほかのメンバーの画面からは見られません。検索やメンションの一覧にも、ほかの人の DM は出ません
- **ただし、RaiseChat の作成者（サーバーを管理している人）は、データベースを直接見られるため、DM の中身も読むことができます。** チャンネルのメッセージ・画像・動画も同じです
- パスワード・カードの番号など、人に知られて困ることは、DM でも送らないでください

## 13. メッセージを探す

1. ヘッダーの「メッセージを検索」に言葉（100 文字まで）を入れて Enter キーを押す
2. 一致したメッセージが新しい順に 20 件ずつ出ます。下までスクロールすると続きが出ます
3. 結果を押すと、そのメッセージの位置が開き、数秒だけ背景の色が変わります

- 探す範囲は、そのワークスペースの公開チャンネル（参加していないものも）・自分が入っているプライベートチャンネル・自分の DM の、メッセージとスレッドの返信です
- 英字の大文字と小文字は区別しません。空白で区切って言葉を並べると、すべてを含むメッセージだけが出ます
- 上の「会話：」と「送った人：」で絞り込めます。「送った人：」は名前を入れて候補から選びます。抜けた人は、ユーザー ID を入れて Enter キーで探せます
- 結果の画面を開いた後に送られたメッセージは、もう一度検索すると出ます

## 14. 通知

### 14.1 サイドバーとワークスペースの一覧の印

| 印 | 意味 |
| --- | --- |
| 会話の名前が太字 | 読んでいないメッセージがある |
| チャンネルの右の丸の数字 | そのチャンネルで読んでいない、自分あてのメンションの数 |
| DM の右の丸の数字 | 読んでいないメッセージの数（100 以上は「99+」） |
| ヘッダーの「@」とサイドバーの「メンション」の数字 | そのワークスペースで読んでいないメンションの合計 |
| ワークスペースの一覧の太字と数字 | そのワークスペースに未読がある。数字はメンションの合計 |

- 印は、開き直さなくてもすぐ変わります
- その会話を開いて画面に出すと、読んだことになり、印が消えます。ほかのタブを前にしている間に届いたものは、そのタブに戻ったときに読んだことになります。別のブラウザで読んだときも消えます
- スレッドの返信の中のメンションは、そのスレッドを開いたときに読んだことになります
- 自分が送ったメッセージは数えません。参加していない公開チャンネルの未読は出ません（メンションは数えます）

### 14.2 メンションの一覧

ヘッダーの「@」かサイドバーの「メンション」を押すと、そのワークスペースで自分あてのメンションが新しい順に出ます。読んでいないものには印が付きます。押すと、そのメッセージの位置が開きます。

### 14.3 ブラウザの通知をオンにする

メンションされたときと DM が届いたときに、パソコンや Android の通知欄にも知らせることができます。初めはオフです。

1. 自分のアバターを押し、メニューの「プロフィールの設定」を押す
2. 「通知」の「ブラウザの通知」を押して「オン」にする（「保存する」は要りません）
3. ブラウザに「通知の表示」の許可を求められたら、「許可」を押す

通知には、送った人の表示名・会話の名前（「#チャンネル名」か「DM」）・本文の初めの 50 文字が出ます（添付だけのときは「画像・動画を送りました」）。通知を押すと、RaiseChat のタブが前に出て、そのメッセージの位置が開きます。

- **通知が出るのは、RaiseChat をどこかのタブで開いている間だけです。** タブを閉じている・ログアウトしているときは出ません。メールやスマートフォンへのプッシュ通知はありません
- その会話を開いていて画面に出ているときは、通知は出ません
- 設定はブラウザごとです。別のブラウザ・別の端末では、そこでもう一度オンにしてください
- iPhone の Safari では通知は出ません。オンにしようとすると「ブラウザの設定で通知が許可されていません。ブラウザの設定から許可してください。」と出ます

#### 「ブラウザの設定で通知が許可されていません。」と出たとき

前に通知を「ブロック」したか、許可を求める画面を閉じています。ブラウザで RaiseChat の通知を許可してから、もう一度オンにしてください。

| ブラウザ | 許可のしかた |
| --- | --- |
| Google Chrome（パソコン） | アドレスバーの左のアイコン（サイトの情報）を押し、「通知」を「許可」にする。出ていなければ「サイトの設定」→「通知」を「許可」にする |
| Microsoft Edge | アドレスバーの左のアイコン（サイトの情報）を押し、「このサイトのアクセス許可」→「通知」を「許可」にする |
| Mozilla Firefox | アドレスバーの左のアイコンを押し、通知の「ブロック中」の横の「×」を押して解除する。その後、もう一度オンにして「許可」を押す |
| Safari（macOS） | メニューの「Safari」→「設定」→「Web サイト」→「通知」で、RaiseChat の URL を「許可」にする |
| Google Chrome（Android） | アドレスバーの左のアイコンを押し、「権限」→「通知」をオンにする |

ブラウザで許可しても出ないときは、OS の設定でブラウザの通知が止まっていないかを確かめてください。

| OS | 確かめる所 |
| --- | --- |
| Windows 11 | 「設定」→「システム」→「通知」で、使っているブラウザがオンになっているか。「応答不可（集中モード）」になっていないか |
| macOS | 「システム設定」→「通知」で、使っているブラウザの「通知を許可」がオンになっているか。「集中モード」になっていないか |
| Android | 「設定」→「アプリ」→「Chrome」→「通知」がオンになっているか |

OS のロック画面に通知が出るかどうかは、OS の設定によります。ロック画面に本文を出したくないときは、OS の設定で止めてください。

### 14.4 共用のパソコンでの注意

**共用のパソコン（家族で使うパソコン、学校・会社・お店のパソコンなど）では、ブラウザの通知をオンにしないでください。**

- 通知には本文の初めの 50 文字が出るので、そばにいる人に DM などの中身を見られます
- **設定はブラウザに残り、ログアウトしても消えません。** 同じブラウザで次に使った人にも、その人あての通知が出るようになります
- オンにしてしまったときは、ログアウトする前に「プロフィールの設定」でオフに戻してください

あわせて、使い終わったら必ずログアウトしてください（2.3）。ログアウトしないと、最後に使ってから 14 日間は、次にそのブラウザを使った人があなたとしてログインしたままになります。

## 15. プロフィール

自分のアバターを押し、メニューの「プロフィールの設定」を押します。変えて「保存する」を押すと「保存しました。」と出ます（「キャンセル」か「←」で、変えずに戻ります）。プロフィールは、入っているすべてのワークスペースで同じです。

| 項目 | 決まり |
| --- | --- |
| アバター | 「画像を選ぶ」で、JPEG・PNG・WebP の 5MB までの画像を選ぶ。真ん中を正方形に切り取って使います。「アバターを外す」でなくすと、表示名の 1 文字目を丸の中に出します |
| ユーザー ID | 出すだけで、変えられません |
| 表示名 | 1〜30 文字 |
| ステータス | いまの状態を、絵文字 1 つ（「😀」から選ぶ）と文（100 文字まで）で表します（例：🏖 休暇中）。どちらか片方だけでもかまいません |
| 消す時刻 | ステータスを自動で消す時刻。「消さない」「30 分後」「1 時間後」「今日の終わり」「1 週間後」から選びます。「ステータスを消す」で、すぐに消せます |
| ブラウザの通知 | 14.3 |

- ステータスの絵文字は名前の右に出て、マウスを乗せると文が出ます。人の名前を押して出るプロフィールには、文と消す時刻が出ます
- 変えたプロフィールは、ほかの人の画面には、その人が次に画面を読み込んだときに出ます

## 16. メッセージが出たとき

| メッセージ | 原因と、すること |
| --- | --- |
| このユーザー ID は使われています。 | ほかの人が使っています。別の ID にしてください |
| ユーザー ID は 3〜15 文字の半角英数字と「_」で入力してください。 | 決まりに合わせて直してください（2.1） |
| パスワードは英字と数字を含む 8〜64 文字の半角文字で入力してください。 | 同上 |
| パスワード（確認）が一致しません。 | 2 つのパスワードを同じにしてください |
| 表示名を入力してください。 | 表示名を 1 文字以上入れてください |
| ユーザー ID かパスワードが違います。 | 入れ直してください。5 回続けて間違えると 15 分間ログインできなくなります |
| ログインに続けて失敗したため、15 分間ログインできません。 | 15 分たってからログインしてください |
| ログインの有効期限が切れました。もう一度ログインしてください。 | 14 日間使わなかったか、安全のためにログインを切りました。ログインし直してください |
| アバターに使えるのは 5MB までの JPEG・PNG・WebP の画像です。 | 別の画像を選んでください |
| ワークスペースの名前を入力してください。 | 名前を 1 文字以上入れてください |
| 作れるワークスペースは 10 個までです。 | 使わないワークスペースを削除してから作ってください（3.3） |
| このワークスペースは見つからないか、参加していません。 | URL が違うか、ワークスペースが削除されたか、ワークスペースから外れています |
| ワークスペース「（名前）」は削除されました。 | オーナーがワークスペースを削除しました |

## 17. できないこと

- 音声・ビデオ通話、画面共有
- 画像・動画以外のファイル（PDF・Office の文書・圧縮ファイルなど）の添付、動画の変換
- 3 人以上・自分あての DM
- @channel・@here など、全員やグループへのメンション
- カスタム絵文字
- スレッドの返信をチャンネルにも送ること、返信への返信
- ピン留め・ブックマーク・リマインダー・予約送信・転送
- チャンネルの名前の変更・アーカイブ、公開とプライベートの切り替え
- オーナーの引き継ぎ、オーナー以外の管理者
- 既読の人・入力中・オンラインかどうかの表示
- メール・スマートフォンへのプッシュ通知、ブラウザのタブの題名への件数の表示
- パスワードの再発行、ユーザー ID の変更、退会
- 削除したメッセージ・チャンネル・ワークスペースの復元
- 日本語以外の表示

不適切なメッセージや画像・動画を見つけたときは、まずワークスペースのオーナーに知らせてください（オーナーは削除できます。7.5）。オーナーが対応しないときは、運営者に知らせてください。
