## 1. 本書について

画面一覧（G-1〜G-18）と画面遷移は[画面一覧](../requirements/screens.md)のとおりで、本書には書かない。本書では、全画面に共通の決まり（2 章）と、画面ごとのレイアウト・表示項目・操作（3 章〜20 章）を決める。表の「操作」の列の ID は、その操作を定めている機能要件である。

### 2.2 文字

| 対象 | 大きさ | 太さ |
| --- | --- | --- |
| アプリ名（ヘッダー）・ワークスペースの名前（サイドバー） | 18px | 太字 |
| 画面の見出し・ダイアログの見出し・会話の見出しの名前 | 18px | 太字 |
| メッセージの表示名 | 15px | 太字 |
| メッセージの本文・入力欄 | 15px | 標準 |
| サイドバーの会話の名前 | 15px | 標準（未読があれば太字） |
| コード・コードブロック | 13px（等幅） | 標準 |
| その他すべて | 14px | 標準 |

書体は、Windows では「メイリオ」または「Yu Gothic UI」、macOS・iOS では「ヒラギノ角ゴシック」、Android では「Noto Sans JP」を使う（OS に入っているものを使い、書体ファイルは配布しない）。コードは各 OS の等幅の書体（Consolas・Menlo など）を使う。絵文字は OS の絵文字の書体で出す。

### 2.3 ボタン

| 種類 | 見た目 | 使う場所 |
| --- | --- | --- |
| 主ボタン | 主色の背景・白い文字 | ログイン、登録する、作る、参加する、保存する、招待する、招待リンクを作る |
| 通常ボタン | 枠線のみ・文字色 | キャンセル、コピー、画像を選ぶ、もう一度、再読み込み、ダウンロード |
| アイコンボタン | 枠なし、32px 四方。マウスを乗せると枠の背景の色 | ＋、×、📎、B・I・S・</>、メッセージの操作（リアクション・スレッドで返信・編集・削除） |
| 危険ボタン | 危険色の背景・白い文字 | 削除、キック、退出、取り消す（ダイアログの中のもの） |

- 高さ 36px、角の丸み 8px、左右の余白 16px（アイコンボタンを除く）
- マウスを乗せるとカーソルを指の形にし、背景を 10% 暗くする
- 押せない状態のときは、透明度 50% で出し、カーソルを禁止マークにする
- アイコンボタンには、何をするボタンかを読み上げられるよう aria-label を付け、マウスを乗せると同じ文を小さな吹き出しで出す
- スマートフォンでは、押せる大きさを 44px 四方以上にする

### 2.5 ダイアログ共通

- 画面の中央に出し、後ろの画面を「背景の覆い」で覆う。開いている間は後ろの画面を操作できない
- 幅は 480px（G-17 は画面いっぱい）。画面の横幅が 600px 未満のときは、横幅いっぱい・下から出す
- Esc キー、または覆いの部分のクリックで、「キャンセル」「閉じる」と同じ動きをする
- G-18 を開いたときは「キャンセル」ボタンにカーソルを置く（Enter キーで誤って削除しないため）
- 閉じたら、開く前に押したボタンにカーソルを戻す

### 2.6 ヘッダー

#### 簡単なヘッダー（G-3・G-10）

```
┌──────────────────────────────────────────────────────────────┐
│ RaiseChat                                    (た) ログアウト │
└──────────────────────────────────────────────────────────────┘
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| アプリ名 | 「RaiseChat」 | 押すと G-3 |
| 自分のアバター | 32px（2.7） | 押すと「プロフィールの設定」（G-10）・「ワークスペースの一覧」（G-3）のメニュー |
| ログアウト | 通常ボタン | 押すと確認なしでログアウトし G-1（A-9） |

#### ワークスペース用のヘッダー（G-5〜G-9・G-11）

```
┌──────────────────────────────────────────────────────────────────────┐
│ RaiseChat ▸ 仲間うち   [🔍 メッセージを検索        ]  @ 2  (た) ログアウト │
└──────────────────────────────────────────────────────────────────────┘
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| アプリ名・ワークスペースの名前 | 「RaiseChat ▸ （名前）」。名前は 20 文字を超えたら「…」で省く | アプリ名で G-3、名前で G-5（最後に開いた会話）（W-5・W-9） |
| 検索欄 | 幅 320px。薄い文字で「メッセージを検索」。100 文字まで。G-6 では検索した文字を入れておく | Enter キーで G-6（SR-1）。トリムして 0 文字のときは M-43（SR-7） |
| 「@」とメンションの件数 | アイコンボタン。読んでいないメンションがあれば件数の丸（2.1）を右上に重ねる | 押すと G-7（NT-2・NT-5） |
| 自分のアバター・ログアウト | 簡単なヘッダーと同じ | |

画面の横幅が 600px 未満のときは、アプリ名を出さず、検索欄は虫めがねのアイコンボタンだけにする。押すとヘッダーの全体が検索欄に変わる。

### 2.7 アバター

| 状態 | 表示 |
| --- | --- |
| アバターの画像がある | 丸く切り取って出す。代わりの文字（alt）は「（表示名）のアバター」 |
| 画像がない、読めない | 枠の背景の色の丸に、表示名の 1 文字目を出す |

| 使う場所 | 直径 |
| --- | --- |
| ヘッダー・サイドバーの DM・ユーザーの行・メンションの候補 | 32px |
| メッセージ | 36px |
| G-16 | 96px |
| G-10 の見本 | 128px |

ステータスの絵文字は、表示名の右に 15px で出す。マウスを乗せると、ステータスの文を吹き出し（title）で出す（PF-5・PF-6）。消す時刻は、メッセージ・一覧の UserSummary には入っていないので、G-16 で出す。

### 2.8 サイドバー（G-5）

```
┌────────────────────┐
│ 仲間うち         ▾ │ ← ワークスペースの名前とメニュー
│                    │
│ @ メンション     2 │
│ 🔍 チャンネルを探す │
│                    │
│ チャンネル       ＋ │
│  # general         │
│  # 旅行の計画   ①  │ ← メンションの件数
│ *# 雑談*           │ ← 未読（太字・強い文字）
│  🔒 運営           │
│                    │
│ ダイレクトメッセージ ＋│
│ *(は) はなこ 🏖 ③* │ ← DM の未読の件数
│  (じ) じろう       │
└────────────────────┘
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| ワークスペースの名前と「▾」 | 2.2 の大きさ | 押すとメニュー：「メンバー」（G-9）、「招待リンクの管理」（オーナーだけ。G-11）、「ワークスペースの一覧」（G-3）（MB-1・I-1・I-9） |
| 「メンション」 | 読んでいないメンションの合計を右に出す | G-7（NT-5） |
| 「チャンネルを探す」 | | G-8（CH-3） |
| 「チャンネル」の「＋」 | アイコンボタン | G-13（CH-1） |
| チャンネルの行 | 「#」か「🔒」と名前。general を先頭に、あとは名前の順。名前が長いときは「…」で省く | 押すと G-5 でその会話（CH-1） |
| 「ダイレクトメッセージ」の「＋」 | アイコンボタン | G-15（DM-2） |
| DM の行 | 相手のアバター（32px）・表示名・ステータスの絵文字。最後のメッセージの新しい順 | 押すと G-5 でその DM（DM-1） |
| 未読の印 | 会話の名前を太字・強い文字にする（NT-1） | |
| 件数の丸 | チャンネルはメンションの件数、DM は未読の件数（100 以上は「99+」）。件数の丸（2.1）に白い数字。読み上げでは「メンション 1 件」「未読 3 件」と読ませる（NT-1・NT-2） | |
| 開いている会話 | 行の背景をサイドバーの選択の色にする | |

サイドバーの幅は 260px（画面の横幅が 600px 以上 1024px 未満のときは 220px）。中身が多いときは、サイドバーの中だけをスクロールする。

### 2.9 メッセージ

```
│ (は) はなこ 🏖  10:02                          [😀][💬][✎][🗑] │ ← 操作は重ねたときだけ
│      **土曜**の集合は駅前でいいですか？ @taro_y                  │
│      [👍 3] [🎉 1] [＋]                                       │
│      (た)(じ) 2 件の返信  最終 10:07                          │
│      10:03  続けて送ったメッセージ（アバター・名前を省く）       │
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| アバター・表示名・ステータスの絵文字 | 2.7。同じ人が 5 分以内に続けて送ったメッセージでは省き、時刻だけを左の余白に、重ねたときだけ出す（MS-12） | 押すと G-16（PF-7） |
| 時刻 | 2.13。編集したメッセージは後ろに補足文字で「（編集済み）」（MS-9） | 時刻に重ねると年月日と秒まで出す |
| 本文 | 2.10 の Markdown の見た目 | リンクは新しいタブで開く（MS-7） |
| 添付 | 2.12 | |
| リアクション | 2.11 | |
| スレッドの返信の件数 | 返信した人のアバター（最大 3 人、20px）と「（件数）件の返信」（主色）と補足文字で「最終 10:07」（TH-2） | 押すとスレッドのパネル（TH-1） |
| メッセージの操作 | メッセージに重ねる（スマートフォンでは長押しで下からメニューを出す）と、右上にアイコンボタンを出す。「リアクション」「スレッドで返信」（親メッセージだけ）、自分のメッセージなら「編集」「削除」、オーナーならほかの人のメッセージにも「削除」。送れない会話ではリアクション・スレッドで返信を出さない | RE-1、TH-1、MS-9、MS-10 |
| 削除された親メッセージ | アバターの代わりに枠の背景の丸、本文の代わりに補足文字で M-33。返信の件数は出す（MS-11） | |
| 送信中 | 透明度 50% で出し、時刻の代わりに「送信中…」（MS-3） | |
| 送信に失敗 | 時刻の代わりに危険色で M-34 と「もう一度送る」「取り消す」（リンク）（MS-13） | |
| 自分へのメンションを含む | メッセージの左端に主色の 3px の線を引き、背景を主色の薄い背景にする（MN-3） | |
| 目立たせたメッセージ | 検索・メンション・通知から開いたメッセージは、背景を主色の薄い背景にし、3 秒かけて元に戻す（MS-14） | |

#### 編集の状態（MS-9）

本文の場所が入力欄（2.14 と同じ見た目）に変わり、下に補足文字で「Esc でキャンセル・Enter で保存」と、通常ボタン「キャンセル」・主ボタン「保存」を出す。添付は「×」付きで並べ、外せる（AT-9）。

#### 会話の中の区切り

| 項目 | 表示 |
| --- | --- |
| 日付の区切り | 区切り線の中央に「11月10日（月）」（前の年以前は「2025年11月10日（月）」）。スクロールしている間は一覧の上に貼り付ける（MS-12） |
| 「新着」の線 | 最初の未読のメッセージの上に、新着の線の色の線と右端に「新着」（MS-1）。会話を開き直すまで残す |
| 会話の始まり | 一覧の上に、チャンネルなら「# （名前）」（18px・太字）と「このチャンネルはここから始まります。」と説明、DM なら相手のアバター（96px）・表示名と「（表示名）さんとのダイレクトメッセージはここから始まります。」（MS-2） |
| 「新しいメッセージ」 | 上の方を見ているときに新しいメッセージが届いたら、入力欄のすぐ上の中央に主ボタン「↓ 新しいメッセージ」を出す。押すといちばん下まで送る（MS-5） |

### 2.10 Markdown の見た目（MS-6・MS-7）

| 書き方 | 見た目 |
| --- | --- |
| `**太字**` | 太字 |
| `*斜体*`・`_斜体_` | 斜体 |
| `~~取り消し線~~` | 取り消し線 |
| `` `コード` `` | 等幅の書体・13px、枠の背景の色、角の丸み 4px |
| 「```」で囲んだもの | 等幅の書体・13px、枠の背景の色の箱（左右の余白 12px）。横に長いときは箱の中だけ横にスクロールする（画面全体は横にスクロールしない。N-29） |
| 行頭の `> ` | 左に枠の背景の色の 4px の線を引き、文字を補足文字の色にする |
| 行頭の `- `・`* `・`1. ` | 箇条書き・番号付きの箇条書き |
| http・https の URL | 主色・下線のリンク。新しいタブで開く |
| 「@ユーザー ID」（記録したもの） | 主色の文字。自分あては主色の薄い背景もつける（MN-3）。押すと G-16 |
| それ以外 | 書いたままの文字 |

### 2.11 リアクション（RE-1〜RE-7）

```
[👍 3] [🎉 1] [＋]
```

| 項目 | 内容 | 操作 |
| --- | --- | --- |

### 2.15 絵文字の一覧（RE-1・PF-5）

幅 352px・高さ 400px の吹き出しで、押したボタンの近くに出す（画面の横幅が 600px 未満のときは、下から横幅いっぱいに出す）。上に検索欄（日本語の名前で探せる）、「最近使ったもの」と分類のタブ、絵文字の一覧、肌の色の選択を並べる。Esc か外側のクリックで閉じる。選ぶと閉じる。

### 2.16 メンションの候補（MN-1）

入力欄の上に、幅 320px の一覧で最大 8 人を出す。1 行は、アバター（32px）・表示名（太字）・@ユーザー ID（補足文字）。会話のメンバーでない人には、右に補足文字で「チャンネルにいません」を出す。上下の矢印で選んでいる行の背景を主色の薄い背景にし、Enter か Tab で入れる。Esc で閉じる。

### 2.17 ユーザーの行（G-9・G-14・G-15 で使う）

```

```

| 項目 | 内容 | 操作 |
| --- | --- | --- |
| アバター・表示名・ステータスの絵文字・@ユーザー ID | 2.7。表示名は太字、@ユーザー ID は補足文字。長いときは「…」で省く | 行を押すと G-16（MB-2） |
| 「オーナー」 | オーナーの行にだけ、補足文字の小さな枠で出す | |
| 右のボタン | 画面ごとに決める（G-9 の「キック」、G-15 は出さないなど） | |

### 2.18 入力の共通ルール

- 前後の空白（半角スペース・全角スペース・タブ・改行）を取り除いてから、文字数の確認と保存を行う
- 文字数は要件定義書の用語「文字数」のとおり、Unicode の文字（コードポイント）単位で数える
- メッセージの本文は、4,000 文字を超えても入力はできる（あとで削れるように）。超えている間は送信できない（MS-4）。それ以外の入力欄は、上限を超える文字を入力できないようにする
- 1 行の入力欄で Enter キーを押すと、その画面の主ボタンと同じ動きをする。日本語の入力の変換を確定するための Enter キーでは送信しない

### 2.19 画面の幅と並べ方

| 画面の横幅 | G-5 の並べ方 | ほかの画面 |
| --- | --- | --- |
| 1024px 以上 | サイドバー（260px）・メッセージの一覧（残り）・スレッドのパネル（開いたとき 400px）を横に並べる | 中身を横幅 720px の 1 列にして、ヘッダーの下・サイドバーの右の中央に置く（G-3・G-10 はサイドバーなしで画面の中央） |
| 600px 以上 1024px 未満 | サイドバー（220px）とメッセージの一覧を並べる。スレッドのパネルは、メッセージの一覧の上に右から重ねて出す（幅 400px） | 同上 |
| 600px 未満 | サイドバー・メッセージの一覧・スレッドのパネルを、1 つずつ画面いっぱいに出す。会話を選ぶとメッセージの一覧、「←」でサイドバーに戻る。スレッドを開くとパネル、「←」でメッセージの一覧に戻る（N-29、TH-6） | 横幅いっぱい（左右の余白 16px） |

375px でも横にスクロールしない（N-29）。長い URL・長い単語は、枠の中で折り返す。

### 2.20 接続の状態（N-9、機能定義書 4.4）

WebSocket が切れている間は、お知らせ欄（2.4）に M-37 を出す。再接続しているあいだ、文の右に小さな回転する印を出す。インターネットにつながっていないときは、M-37 の代わりに M-50 を出す。切れている間も、入力欄に文を入れることはできる。送信は API で行うので、インターネットにつながっていれば送れる。
